## Schema change

One new table, additive only — no destructive migration:

```sql
create table if not exists board_touchpoints (
  id uuid primary key default gen_random_uuid(),
  touch_date date not null default current_date,
  role text not null check (role in ('Coach','Mentor','Role Model','Expert','Accountability Partner','Complementary Partner','Person with Shared Interest')),
  person text not null,
  minutes int,
  note text,
  created_at timestamptz default now()
);
alter table board_touchpoints enable row level security;
create policy "anon full access" on board_touchpoints for all using (true) with check (true);
```

Sha needs to run this once against her Supabase project — easiest path is the existing **"Copy schema"** button in Tended's Settings drawer, which copies the *entire* embedded `schemaSqlBlob` (all tables, `create table if not exists` + idempotent policy `drop`/`create` throughout) and is safe to paste into the Supabase SQL Editor and run again even though the other tables already exist. No separate migration file needed for a single new table.
